# dev-disk-doctor

Find out why your developer machine's disk is full, and get safe, explained ways to fix it.

> Work in progress. Planned: a read-only disk scan (Docker, Android SDK, Xcode, package caches, ML models, `node_modules`), a git worktree audit that finds orphaned worktrees across all your repos, and an MCP server so an AI agent can run it and walk you through the options.
